# Lateral Entry & Branch Upgrade Editability Policy

## Design Requirement
Auto-filling profile fields must NEVER lock or disable user input.
- **Branch Upgrades:** Students whose branch was upgraded in 2nd year retain their original roll number but belong to a new department.
- **Lateral Entry:** 3-year B.Tech students graduate 1 year earlier.
- **Postgraduate Programs:** MCA, MBA, M.Tech have distinct durations.
