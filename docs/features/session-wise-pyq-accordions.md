# Session-Wise PYQ Accordion Grouping

## Architecture
Exam question papers are structured hierarchically:
- 2026-27 (Current Session)
- 2025-26
- 2024-25
- 2023-24
- 2022-23 & Earlier Archives
- Additional / General Papers

## Safeguards
Every single paper is categorized without loss. The component features built-in search and direct Google Drive links.
